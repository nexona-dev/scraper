# Nexona Scraper - E-commerce Price Tracker

A Python web scraper that extracts book titles, prices, stock status, and ratings from books.toscrape.com and saves them to a CSV file.

## Features
- Scrapes 1000+ products in under 2 minutes
- Cleans and structures data automatically
- Saves output to CSV for easy analysis

## How to Run
1. Install dependencies: `pip install -r requirements.txt`
2. Run the script: `python scraper.py`

## Result
1000 book records saved to `books_prices.csv`. Reduces manual data collection time from hours to seconds.

## Tech Stack
Python, BeautifulSoup, Requests, Pandas
